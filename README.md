It's a React hook to add easter eggs that activate with a cheatcode


## Installation

```
npm install use-easter-egg
```

## Usage

```js
  useEaster([{ code: "mortalkombat", egg: <img src="toasty.png"> }]);
```

Now go to your app and type "mortalkombat"
